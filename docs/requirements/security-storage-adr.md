# ADR：阶段一单管理员内部安全状态

日期：2026-10-27。状态：实现中，待完整迁移与平台验收。

采用标准库 JSON 文件和 POSIX 独占文件锁，不增加内容数据库。三个现有 YAML 仍是内容事实来源。`internal/security` 仅保存实例随机标识、单管理员 Argon2id 哈希、密码来源模式、安全世代、会话令牌摘要与时间高水位。

## 文件与事务

`.flare-security/` 为 0700；`state.json`、`complete`、`commit.json` 和锁文件为 0600。状态信封带 SHA-256 校验用于发现意外损坏，不声称防御已经拥有目录写权限的人。状态内带版本及实例 ID，完成标记与其对照。完成后缺失任一状态/标记均拒绝重新初始化。整个目录被删除无法辨别历史安装，此限制仍适用。

事务先写并同步完整提交意图 `commit.json`，再原子替换并同步状态，最后删除提交日志并同步目录。首次初始化还写入并同步完成标记；已初始化实例先校验现有不可变标记，后续事务不重复改写它。有效日志重放仍可补齐标记。标记丢失或不匹配在新日志发布前进入故障关闭。同目录临时文件、文件同步、rename、目录同步构成落盘协议。运行时任何写错误使当前 Store faulted，不能继续使用旧授权状态。重启对有效提交意图幂等重放；日志损坏或实例不匹配拒绝启动。日志提交前失败保留原状态；提交意图成功后重启可以完成新状态，因此调用者必须把任何存储错误作为业务不可用，不能承诺操作必定未发生。

`instance.lock` 使用 POSIX flock，在 Open 至 Close 全程持有；第二服务或维护 CLI 拒绝打开。仅支持本地盘单写进程；不支持共享网络盘、多副本和 Windows 原生目标。当前依赖 x/sys/unix 已存在，无新增数据库驱动或 CGO。本次 macOS arm64 原生构建及 Linux amd64/arm64 交叉构建已通过；对应设备与 CI 运行证据仍需补充，不能凭交叉构建签署真机验收。

首次迁移原始 YAML/旧安全文件快照、输入摘要与来源记录由迁移协调层建立，必须在 Initialize 前成功，且不能把本存储日志当成完整部署备份。无管理员可信模式与待处理识别也由协调层决定；Store 不推断内容或运行配置。

## 密码与会话

Argon2id 固定初始参数 m=19456 KiB、t=2、p=1，16 字节独立随机盐与 32 字节结果，参数持久化并校验。全进程哈希并发 1，最多 8 个等待，等待 10 秒上限；未知用户名使用同参数虚拟验证。初始化/部署更新可保留旧非空短密码；新改密和本地恢复执行 15–128 码点、最多 512 字节及弱口令检查。弱口令策略读取随二进制嵌入的 `internal/security/common-passwords.txt` v1，覆盖常见长默认口令、公开示例和数字/键盘序列，并拒绝 1–4 码点单元反复组成的口令。字典为明确版本的针对性拒绝表，不宣称穷尽泄漏密码；认证比较仍保留原值，不应用策略中的大小写比较。

令牌为 32 随机字节，只保存 SHA-256 摘要。服务端检查闲置 30 分钟、绝对 12 小时和安全世代；普通活动仅更新闲置时间。重新认证轮换令牌并保留原绝对期限。密码更新、来源切换和全退出与清会话同事务，同部署输入重启不撤销。会话数上限 4096，签发时清理过期会话。

每个 HTTP 请求首次有效会话校验推进持久时间高水位，成功前台读取返回前再次持久校验。请求内重复读取使用仅属于当前 Store/请求的认证证明，实时检查撤销、世代、存储故障及最新已持久化时间下的过期；它不观察未落盘的新墙上时间。证明以单调时钟限时一秒，超过后走完整持久校验；跨请求不复用。写入、导出和最近认证检查继续走实时完整校验。HEAD 返回前完整校验但不续闲置时间。回拨超过 60 秒先持久撤销全部会话再重设基准，小回拨钳制；已观察到的过期会话删除且不可复活。写入失败关闭存储。请求内复用减少重复校验和写入，不改变密码参数、会话期限或写入故障关闭要求。若成功 GET/HEAD 在内容生成后被最终校验发现撤销，丢弃已生成内容并返回 401；故障返回 503。20,000 条前后对比见管理员性能专项，低配 ARM/NAS 仍需真机测量。

## 已有自动测试

覆盖正常重启、精确旧用户名/密码、锁冲突、秘密不落明文、文件权限、闲置到期、重新认证轮换与绝对期限保持、单会话撤销、改密撤销、相同部署输入幂等、部署来源约束、状态/标记损坏、事务各写阶段故障重放、回拨与跨重启撤销、密码格式、版本化弱口令表与重复模式、单次授权内容提交与撤销并发顺序。

迁移中断、真实 tmpfs 满、完整恢复、HTTP 撤销、压力和构建证据见综合验收及专项记录；真实硬件掉电及低配平台仍未验证。此 ADR 不等于阶段一验收签署。

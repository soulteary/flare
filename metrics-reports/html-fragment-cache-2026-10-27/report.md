# HTML 片段缓存第一阶段验证

2026-10-27，Apple M5，darwin/arm64，Go 1.27.3。三轮各 2 秒原生 HTTP 基准，纯片段基准三轮各 500ms。结果取每个指标的三轮中位数，不是合并请求后的百分位数。

## 实现范围

请求级只读设置快照（包括错误），首页/帮助页天气复用设置；不可变授权导航视图；默认无搜索导航 HTML 缓存。公开与管理员视图隔离，键包含内容身份、配置 revision、展示选项、路由与主题代际。命中先于集合复制和渲染，仍执行文件检查与最终持久化授权。

缓存上限 16 MiB HTML、64 个条目、单条 1 MiB，FIFO 淘汰及同键构建合并。搜索、选中分类、编码/扩展跳转及动态 URL 绕过。旧版本条目通过版本键不可达并按容量淘汰；不改变在途请求的快照语义。

## 原生 TCP 首页结果

每集合 1,000 条公开导航及一条私有哨兵，离线首页，单连接顺序 keep-alive，三种身份分别测试。使用真实首页处理器、模板引擎及持久化认证中间件；测试装配不包含生产路由的来源保护和访问日志。客户端与服务器在同一 Go 进程中运行，分配指标包含两者。每次响应均检查 HTTP 200 和与预热响应相同的长度。

- 关闭登录：p50 0.7524 → 0.2302 ms；p95 1.0800 → 0.5150 ms；完成速率 1246.00 → 3590.00 req/s；分配 2501.6 → 1330.3 KiB/op（减少 46.8%）。
- 开启登录未登录：p50 0.7665 → 0.2575 ms；p95 1.2700 → 0.5384 ms；完成速率 1165.00 → 3299.00 req/s；分配 2454.8 → 1363.8 KiB/op（减少 44.4%）。
- 开启登录已登录：p50 24.5800 → 23.3900 ms；p95 27.8000 → 25.8300 ms；完成速率 40.55 → 42.76 req/s；分配 2484.9 → 1344.0 KiB/op（减少 45.9%）。

“冷”指每个请求清空 HTML 条目，YAML 字节及解析快照仍为热状态，不是冷启动。清理成本计入 ns/op 和分配总量，但不计入逐请求 p50/p95 采样。没有将冷缓存视为原版本的严格前后对照；已登录请求保留同步安全事务。

## 纯应用片段结果

- 100 条公开应用加私有哨兵：无缓存 22.27 µs、67323 B/op、104 allocs/op；冷缓存 25.48 µs；热命中 52.89 ns、0 B/op、0 allocs/op。
- 1000 条公开应用加私有哨兵：无缓存 201.49 µs、627766 B/op、1004 allocs/op；冷缓存 240.62 µs；热命中 53.95 ns、0 B/op、0 allocs/op。

纯片段基准预先选定授权数据视图，热命中只是不可变字符串查找，不包含每请求配置读取、文件检查、HTML 输出复制或网络。1 万条应用片段超过 1 MiB 上限，明确使用 oversize-bypass；三轮结果未显示缓存收益，也不会将其算为命中。

## 正确性与限制

- `go test ./...` 全量通过；首次 baseline 测试因测试环境禁止监听端口而未能执行；启用回环监听后重跑通过，最终日志见 go-test.txt。
- data、define、home、server 包完整竞态回归通过；新增 home 安全测试另外完成定向竞态复查。
- `go vet ./...` 和 `git diff --check` 通过。
- 覆盖三种身份、管理员缓存预热后的匿名隔离、配置外部修改、导航/ACL 保存失效、删除已缓存 backing 文件、会话撤销、独立会话 CSRF、Store 故障、动态与编码 URL、容量限制、并发同键构建和旧版本构建、主题 ABA 变化及请求级设置错误复用。
- 使用现有 HTML fixture/golden 和全量页面回归验证渲染行为；本轮没有修改认证持久化协议或 HTTP 私有响应缓存策略。
- 没有进行多客户端饱和、浏览器性能、RSS 峰值、长期运行或远程网络测量；三轮样本没有置信区间。
- 大片段、搜索和动态链接仍可能每次渲染；不能由热片段查找耗时推导全站 QPS。
